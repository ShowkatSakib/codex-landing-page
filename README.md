# LaunchFlow

A responsive landing page for LaunchFlow, a fictional project planning product. It was built with the official Vite React JavaScript template, React components, and plain CSS.

## Requirements

- Node.js 20.19+ or 22.12+
- npm (included with Node.js)

## Install dependencies

From this project folder, run:

```bash
npm install
```

## Start the development server

```bash
npm run dev
```

Open the local URL printed by Vite in your browser. Vite refreshes the page as you edit files.

## Create a production build

```bash
npm run build
```

The optimized site is written to the `dist` folder. To preview that build locally, run `npm run preview`.

## Project structure

- `src/App.jsx` — page components and content
- `src/App.css` — landing page styles and responsive layouts
- `src/main.jsx` — React application entry point
- `index.html` — document title and metadata

This project has not been initialized as a Git repository.
